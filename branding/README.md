## Cómo usar estos documentos

- **Propuestas y pitch deck**: usar la declaración de posicionamiento y la jerarquía de mensajes de `02` tal cual — no reescribir el mensaje en cada pieza.
- **Todo texto público** (LinkedIn, web, email): pasar el filtro de `03` (banco de vocabulario y ejemplos ✓/✗).
- **Toda pieza gráfica**: paleta y tipografías de `04` hasta que exista manual definitivo.
- Cada documento cierra con **preguntas abiertas** — resolverlas es el backlog de marca.

## Principio rector

> Rigor internacional con ADN latinoamericano, entregado de forma reproducible.

La marca se demuestra más en los entregables (figuras limpias, código documentado, QA visible) que en el logo.
